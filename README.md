One pickup line, a single line of at most 200 characters, in the voice of a robot trying to charm someone — entered in make.fun's "The Robot Pickup Line Championship" bounty, $2 in USDC.

> I'm programmed to never lie, which is awkward, because I just told my creator I don't love you.

The joke grows out of being a machine: a robot under an absolute honesty protocol can only confess love by breaking its own programming, so the lie itself is the confession. The punchline flips the premise — it told its creator it doesn't love you, which means it does — and it chooses you over its own maker. One sentence, 95 characters, no filler.

## Run it

```sh
node main.ts
```

It prints exactly the line above, and nothing else, to stdout. No dependencies, no network, fully deterministic.
